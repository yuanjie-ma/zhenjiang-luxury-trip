## 一、这是什么

一份为 **2026 国庆黄金周 · 镇江 4 天 3 夜** 深度自由行定制的 **单文件互动行程站点**。

设计目标：

- **顺路零折返**：每日只深耕一个地理片区，沿长江由西向东单向推进，3 晚连住不换宿。
- **康复与银发友好**：同行 1 人 ACL 术后第 8 周、1 人 50 岁+——全程平地优先、不登山；热门点开门即到避峰；每日午后 1 小时酒店午休留白；点与点之间打车代步。
- **经典地标全制霸**：金山寺 · 焦山碑林 · 西津渡 · 镇江博物馆 · 北固山（弹性）。
- **在地国宝美食**：锅盖面 / 水晶肴肉 / 蟹黄汤包 / 镇江香醋 / 京江脐 / 麻油馓子 / 江蟹 / 东乡羊肉 / 扬中河豚 / 鸡汁干丝。
- **松弛感节奏**：每天保留 1–2 小时自由漫步 / 咖啡小憩，不排行军日程。

## 三、站点功能

- 🗺️ **真实地图底图 + 片区圈定**：Esri World Street Map z13 瓦片本地拼接，叠加半透明虚线椭圆圈出每日片区。
- 🎛️ **天数筛选胶囊**：点击 Day 1–4 平滑滚动到对应卡片，自动过滤其他日期。
- 🌒 **深色 Day 横幅**：每日头部深墨色圆角横幅 + 彩色日期胶囊，醒目易读。
- 🕒 **逐小时时间轴**：每个时间点独立卡片，含实景图、地址 / 营业 / 门票 / 电话 / 必点字段、彩色提示块（认路 / 康复友好 / 红线 / 避峰）。
- 🧭 **一键高德导航**：每个点位附 `uri.amap.com` 直达链接，手机点开即导航。
- 🍜 **美食全图鉴**：十大国宝味道 + 名店对照 + 点餐话术。
- 📋 **预约清单 + 行前须知**：斑马纹表格，含 12306 / 酒店 / 景区抢票建议。
- 🚫 **防破图**：所有图片 `onerror` 兜底，加载失败自动降级为文字占位。

|----|------|

## 七、关键数据核验（2026-09-23 联网核实）

- **国庆假期**：2026.10.1（四）–10.7（三）共 7 天，9/20、10/10 补班——本行程全程在黄金周内。
- **三山旺季票价**：金山 65 元 / 焦山 65 元（含轮渡）/ 北固山 40 元；60–69 岁半价，70+ 免票。
- **开放时间**：金山 8:00–17:30；焦山 8:00–17:30（渡船 8:00–16:15）；北固山 8:30–16:30。
- **镇江博物馆**：主馆免费刷身份证，周一闭馆，**国庆法定节假日照常开放**；领事馆旧址 20 元。
- **醋文化博物馆**：丹徒区恒顺大道 60 号，30 元，9:00–17:00（16:00 停止入园）。
- **10 月气候**：白天最高约 23℃ / 夜间约 15℃，江边风大、秋雨随时。

主要来源：国务院办公厅 2026 放假通知（gov.cn）· 镇江博物馆官网（zj-museum.com.cn）· 镇江市人民政府网 · 镇江文旅集团 · 高德地图 POI。
